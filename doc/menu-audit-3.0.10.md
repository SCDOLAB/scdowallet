# Menu audit 3.0.10

There is no left sidebar. The header is the logo and the status island; the account chip (`accChip` / `hdrLang`) has not been drawn since 3.0.2. Version stays 3.0.10. Each action below was reachable from more than one place. One primary place is kept. Nothing in this list was deleted as a capability.

| action | all current locations | kept location | removed locations |

| 開始挖礦 | 首頁挖礦卡片；檔案 → 開始挖礦；挖礦設定頁（Shard0 EVM 與 Shard1–Shard4 Classic）的大按鈕；AI小貓「開始／停止挖礦」 | 首頁挖礦卡片 | 檔案選單、挖礦設定頁的開始按鈕、AI小貓那一列 |
