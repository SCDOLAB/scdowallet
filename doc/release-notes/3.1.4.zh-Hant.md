# SCDO 錢包 3.1.4 版本說明（2026-10-12）

- **放棄後自動重試。** 挖礦守護放棄某個礦工程式後，冷卻一段時間會自動重試，不必再手動重新開始挖礦。
- **開啟時自動恢復。** 「持續挖礦」開啟時，錢包被關閉、強制結束或當機後再次開啟，會自動恢復之前正在挖的鏈。
- **AI 代理帳本客戶端。** 每台礦機以自己的金鑰註冊為代理，自行簽署心跳和自我修復紀錄。帳本伺服器只驗證簽章，不持有任何私鑰。公開頁面：https://scdoscan.io/agent-ledger/zh/
- **AI 貓溫度保護。** 顯示卡 85–94°C 只會提醒；95°C 以上才停止挖礦。日誌會記錄為溫度保護，而不是使用者停止。
- **CPU 本次收益重新開始後保留。** 挖礦重新開始、重新開啟錢包、自動恢復或網路重新連線後，「本次收益」的份額和收益不再歸零；只有按「停止」才會重新計算。AI 代理帳本的心跳現在也會回報算力、節點連線數和區塊高度。
