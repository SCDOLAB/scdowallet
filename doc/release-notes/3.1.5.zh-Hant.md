# SCDO 錢包 3.1.5 版本說明（2026-10-16）

- **Shard0 改走墨爾本。** 顯示卡礦池預設是 `139.84.196.31:3333`。Shard0 引導節點使用同一把 enode 金鑰，位址改為 `139.84.196.31:30368`。已經存好的礦池位址不會被改掉；先前的官方位址仍視為官方礦池，出塊進度照常顯示。
- **Shard1 到 Shard4 先維持原礦池。** 預設主機仍是 `82.223.19.88`（stratum 3341–3344，統計 8341–8344）。遠端設定可以覆寫主機或連接埠。`SCDO_ZPOW_POOLS` 仍優先於那份設定。

- **AI 代理帳本。** 客戶端先送到 `https://apeccapital.org/agent-ledger/api`，失敗再送到 `https://scdoscan.io/agent-ledger/api`。註冊時帶上出塊地址。礦機會回報 N 小時沒有入帳（預設 24）、礦池斷線，以及出塊餘額過久沒有更新。送不出去會重試，並寫進本機代理紀錄。當機和未處理的錯誤會簽名後送到 `/report`。
- **允許 apeccapital.org。** 錢包裡打開的連結、頁面連線政策，以及更新程式的下載來源都接受這個網域。安裝檔仍要通過原本的簽章檢查。
