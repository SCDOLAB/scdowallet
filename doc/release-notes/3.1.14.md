# SCDO Wallet 3.1.14 (not released yet; the CEO decides the release)

- **SCDO points auto-play (client ready, still Coming soon).** The wallet now contains the real Stake Wheel auto-play client for Reward destination A. The toggle stays disabled and marked Coming soon until the server capability (`/features` → `rewardWheel`) is switched on; it is off by default. Once on, auto-play is opt-in per user and off by default; each start is confirmed with the wallet password, which signs the server challenge and prepays the session in SCDO points (10 or 100 points per round, 1 round per minute, capped by the loss limit). Stop is always available. "Not available in your region" (403) turns the option off; "Wheel paused, pool refilling" (503) pauses the session.
- **Lend to treasury for interest** stays Coming soon.
- Not shown in App Store or Play builds.
