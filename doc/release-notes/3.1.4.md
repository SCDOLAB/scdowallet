# SCDO Wallet 3.1.4 release notes (2026-10-12)

- **Give-up auto-retry.** When the mining guard gives up on a miner, it now retries automatically after a cool-down instead of staying stopped until you restart mining by hand.
- **Auto-resume on launch.** With *Keep mining* on, the chains that were mining resume automatically when the wallet is opened again after it was closed, killed or crashed.
- **AI Agent Ledger client.** Each rig registers as an agent with its own key and signs its own heartbeats and self-heal events. The ledger server only checks signatures and holds no private keys. Public page: https://scdoscan.io/agent-ledger/
- **AI cat heat guard.** A graphics card at 85-94°C gets a warning only; mining is stopped only at 95°C or above. The log records this as the heat guard, not as a user stop.
- **CPU session earnings kept across restarts.** *This session* shares and earnings no longer jump back to 0 after a mining restart, wallet relaunch, auto-resume or network reconnect; only pressing Stop starts a new count. The heartbeat to the AI Agent Ledger now also carries hashrate, node peers and block height.
