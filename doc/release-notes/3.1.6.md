# SCDO Wallet 3.1.6

- The Mac app includes the processor miner and is notarized by Apple. Apple silicon needs Rosetta 2.
- The wallet no longer has a built-in address for the old Shard1 to Shard4 pools and no longer contacts it. The remote configuration names the pools once they open.
- Shard0 EVM mining uses the Melbourne pool (139.84.196.31:3333) only.
- The Mac now has its own update feed (https://scdo.com.au/downloads/wallet/mac/latest.json) and is no longer offered the Windows installer.
- Create account offers shard 0 (Shard0 EVM, the default); 1 to 4 are Shard1–4 Classic.
- The password rule is shown once and turns red only when the password does not meet it.
