# SCDO Wallet 3.1.5 release notes (2026-10-16)

- **Melbourne Shard0.** The graphics-card pool default is `139.84.196.31:3333`. The Shard0 bootnode is the same enode key on `139.84.196.31:30368`. A saved pool address is left as it is; the previous official host is still treated as the official pool for payout progress.
- **Shard1–Shard4 pools stay put.** The default host is still `82.223.19.88` (stratum 3341–3344, stats 8341–8344). A remote config document can override a host or port. `SCDO_ZPOW_POOLS` still wins over that document.
- **Public RPC.** The third-party hosts `74.208.207.184`, `117.50.97.136` and `107.150.102.94` are no longer used. Each shard defaults to `https://apeccapital.org/rpc/N` and falls back to `https://scdoscan.io/rpc/N`. A remote config `rpc` list replaces that order. Saved custom endpoints are kept.
- **AI agent ledger.** The client posts to `https://apeccapital.org/agent-ledger/api` and falls back to `https://scdoscan.io/agent-ledger/api`. Registration includes the payout address. The rig reports no reward for N hours (default 24), a disconnected pool, and a stale payout balance. Failed posts are retried and written to the local agent log. Crashes and unhandled errors are signed and posted to `/report`.
- **apeccapital.org is allowed** for links opened from the wallet, for the page connect policy, and as an updater download origin. Installers still have to pass the existing signature check.
