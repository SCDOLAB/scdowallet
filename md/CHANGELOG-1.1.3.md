# ScdoWalletBeta 1.1.3 (2026-09-29)

- Send page: the asset is now chosen from a dropdown menu, like MetaMask. The button shows the chosen asset's
  icon, symbol and balance. The menu lists every asset of the current network: native SCDO first, then the
  tokens configured for shard0 (tUSDT, tAUD), each with icon, symbol, name and balance, and a check mark on the current one.
  The dropdown is on the address step and on the amount step (switching the asset clears the amount and re-estimates the fee).
  Keyboard: arrow keys move through the list, Enter picks, Esc closes the menu (a second Esc closes the dialog).
- Home > Assets uses the same icons and asset list as the dropdown.
- Version / About / changelog text updated to 1.1.3. No changes to keyfiles, mining, node or network code.
